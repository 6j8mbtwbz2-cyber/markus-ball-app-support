Your photo import in five steps

  1. Add a source

    Drag photos or a folder from Finder into the import area, or select images using Finder.

  2. Check the destination

    Choose a destination folder. Set the date-based folder structure under Settings → Folders.

  3. Choose detection options

    Enable focus or HDR detection for the relevant images. Check time gaps, the minimum image count and HDR sequence sizes.

  4. Open the import preview

    Review planned folders, detected sequences and duplicates. Adjust detection for this import if needed.

  5. Start importing

    Start the reviewed import. The app copies images and keeps the original source files.

Frequently asked questions

Are my original photos moved or deleted?

FotoStack Importer copies images to the destination. Original source files remain unchanged. Processing takes place locally on your Mac.

Read more in the manual

Why was my focus or HDR sequence not detected?

Check detection options, time gaps and minimum image count in the preview. Focus sequences must match any enabled close-focus or focal-length filters. HDR also requires an enabled sequence size and readable, matching EXIF exposure data.

Read more in the manual

Why was a normal burst detected as a focus sequence?

Bursts and focus sequences can have similar time gaps. Review the preview, increase the minimum image count if needed, or disable focus detection for wildlife, sports and action bursts.

Read more in the manual

Why are some images not imported again?

Duplicate detection compares file contents, including renamed files. If all images are already present, the preview offers “Show duplicates” instead of a new import. Incomplete sequences are completed in their existing folders.

Read more in the manual

Why is a sidecar added when its image already exists?

Sidecars are checked separately from image duplicates. Missing sidecars are added. An existing destination sidecar is replaced only by a newer source file when “Copy source sidecars” is enabled. Backups can be enabled in Settings.

Read more in the manual

Why must I grant folder access again?

The app stores permission for the photo base folder and its subfolders. Select it again if it was moved or deleted, or if its permission is no longer valid. Folders outside this area require a separate selection.

Read more in the manual

Why is the source folder structure not preserved?

FotoStack Importer creates the selected structure using capture dates and detected sequences. Settings → Folders offers year, month and date folders, or no date subfolders. Detected sequences still get their own folders.

Read more in the manual

Why can’t I start importing?

Check free space and destination permissions. If all images already exist, there are no new images to copy; open the duplicate overview. Sidecar-only updates also require the appropriate sidecar setting.

Read more in the manual
