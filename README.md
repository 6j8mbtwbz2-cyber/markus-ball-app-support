# Markus Ball App Support

Public support pages and user manuals for apps by Markus Ball.

The published site contains documentation only. Application source code is maintained separately.

LocalCast Audio support is available at `localcastaudio/` (German) and `localcastaudio/en/` (English quick start and FAQs). Its complete German user manual is at `localcastaudio/de/`, exported from the app's `docs/handbuch` on 4 November 2026. When refreshing the export, keep the support navigation and canonical URL in the web copy. The supplied logo is stored unchanged in `localcastaudio/assets/`. Contact links reuse the address published in the site's legal notice. No application source code is included.
