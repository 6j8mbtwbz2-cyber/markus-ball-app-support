Usage and Safety Information

Information for the safe use of the macOS apps described on this website

Last updated: September 7, 2026

The apps assist with workflows and calculations. Results also depend on the selected settings, source data, equipment, ingredients, and environmental conditions. Check important results before taking further steps that cannot easily be reversed.

FotoStack Importer

FotoStack Importer copies selected image and sidecar files to the chosen destination. Original files in the source folder are not moved or deleted during import. Before starting, check the source, destination, import preview, available storage, and planned folder structure.

Keeping a separate backup is nevertheless recommended. In particular, the settings selected in the app apply when existing sidecar files are updated.

PhotoCaptureTime

PhotoCaptureTime renames the selected files according to the displayed preview. The contents of the files are intended to remain unchanged, but file names and file paths are changed directly. Before executing the operation, check the file selection, retained image number, all name components, possible naming conflicts, and the complete preview.

Recommendation: Keep a current backup before large rename operations and test new settings on a few copied sample files first. Do not quit the app during an active rename operation or disconnect any drive involved.

GeniusHDR GainMap Studio

GeniusHDR GainMap Studio embeds a gain map in the exported image file and thereby changes its technical structure. If the corresponding option is selected, the output file is also renamed. Before exporting, check the preview, HDR effect, output format, file name, and destination.

Important: A gain map embedded using this app cannot be removed from the image file by the app. Therefore, keep the original source image independently of all exported results.

Appearance and compatibility may vary depending on the display, operating system, image software, and file format.
